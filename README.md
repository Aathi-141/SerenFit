# 🌙 SerenFit – Wellness & Habit Tracking App

SerenFit is a native Android wellness application designed to help users build consistent habits, track emotional well-being, and maintain a healthier daily routine—all within a calm and visually soothing environment.

With its night-purple themed interface, SerenFit creates a peaceful digital space that encourages focus, reflection, and personal growth.

---

## ✨ Features

- ✅ **Daily Habit Tracker**  
  Create, edit, and track habits with automatic daily progress reset.

- 💧 **Hydration Reminder**  
  Stay hydrated with customizable notification reminders.

- 🧠 **Mood Journal**  
  Log daily emotions with notes and view them in a calendar format.

- 📊 **Mood Trend Analytics**  
  Analyze weekly emotional patterns through simple visual insights.

- 📅 **History Tracking**  
  Access past records of habits, hydration, and mood logs.

- ⚡ **Offline Functionality**  
  Data is stored locally for fast and seamless performance.
